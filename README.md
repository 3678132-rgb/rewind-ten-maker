# 다시, 스무 살 (Rewind Ten)

마흔에 이혼하고 해고된 주인공이 시간 약방 할머니의 약을 먹고 2006년의 스무 살로 되감긴다.
**십 년(120개월) 안에** 일·관계·나 세 축을 모두 50 이상 세우면 시계가 온전히 내 것이 되고(자유 엔딩),
못 하면 비 오는 골목의 마흔으로 돌아간다(회귀 엔딩). 「스테이지 제로 메이커」(1편)의 육성 시뮬레이션 엔진을 새 세계관으로 다시 짠 게임.

## 화면
모바일 세로 9:16 풀스크린. 타이틀·메인·활동·이벤트·엔딩 모두 일러스트가 화면을 채우고 UI를 얹는다. 폰에서는 화면 전체, 데스크톱에서는 9:16 프레임을 가운데에 둔다.

## 실행
`index.html`을 브라우저로 열면 된다 (단일 파일, 외부 의존성 없음).

## 개발
```
src/engine.js         상태·활동·정산 (DOM 금지)
src/data/lovers.js    연애 인물 4명과 연애 이벤트
src/data/events.js    스토리·시대(2006~2016)·랜덤 이벤트
src/data/endings.js   엔딩 판정과 편지 (12종)
src/ui.js, style.css, shell.html   화면
build.mjs             src → index.html
sim.mjs               자동 플레이 테스트
```
```
node build.mjs        # index.html 생성
node sim.mjs 1500     # 오류 {} 이고 smart 자유율 ≈ 70%, random ≈ 0% 이면 정상
```
`// ==ENGINE==` ~ `// ==/ENGINE==` 구간(engine/lovers/events/endings)에는 DOM 코드를 넣지 않는다.

## 핵심 규칙
- **학과·직업**: 한국대학교 학과 10종 중 선택 → 3학년 진로 탐색(인턴) → 졸업 때 직업 7종(뷰티 마케터·프로덕션 PD·드라마 작가·연예인·로펌 변호사·IT 개발자·패션 디자이너) 지원. 직업마다 같은 일터의 연애 상대가 있다.
- **3축**: 일·관계·나. 한쪽만 하면 나머지가 마른다(균형).
- **기억 선명도**: 미래 지식을 쓸수록 흐려진다. 쓴 만큼 「빌린 인생」이 쌓이고 일 점수가 깎인다.
- **연애**: 공식 연인은 한 명. 서재우(전남편)는 습관을 고치지 못하면 결혼이 되풀이된다.
- 월 3칸 스케줄 → 결과 → 이벤트. 시대 이벤트: 2008 금융위기, 2009 아이폰, 2010 카카오톡, 2012 여름.

세계관 설정은 `docs/WORLD.md`.

## 그림 (art/)
Higgsfield `gpt_image_2_5`로 생성. 주인공 일관성은 확정 시안(age20)을 레퍼런스로 걸어 나이대별로 다시 그리게 해서 유지한다.
`age20/22/25/27/30.webp`(주인공 나이대별), `cover.webp`(타이틀·회귀 엔딩), `face_*.webp`(주인공 표정 6종), `face_<인물>_<표정>.webp`(연애 인물 11명 × 6종), `job_<직업>[_27|_30].webp`(직업별·나이대별 근무), `duo_<인물>.webp`(연인과 함께 일하는 장면), `bg_shop.webp`·`bg_alley.webp`(배경), `lv_*.webp`(서재우·민준·하진·태오), `mom.webp`, `soyeon.webp`, `grandma.webp`.

## 설치형 앱(PWA)과 배포
- `node build.mjs` 가 `index.html` 과 `sw.js`(서비스워커: 그림 목록·캐시 버전 자동 생성)를 만든다. `manifest.json`·아이콘은 저장소 루트에 있다.
- 그림은 `tools/to_webp.py` 로 WebP로 줄인다(약 14MB → 약 6MB). 새 그림을 `art/`에 jpg/png로 넣고 이 스크립트를 돌린 뒤 `node build.mjs`.
- **GitHub Pages**: 저장소 Settings → Pages → Branch `main` / `/ (root)` 저장. 폰 브라우저에서 열고 「홈 화면에 추가」 하면 앱처럼 실행된다.
- 서비스워커는 화면 틀(index.html)을 인터넷이 되면 항상 최신으로 받고, 그림은 처음 쓰일 때 기기에 저장한다(두 번째부터 즉시·오프라인 가능).

## 화면(UX) 원칙
- 글자는 최소 13px, 본문 15~17px. 버튼 높이 44px 이상.
- 메인: 상단에 날짜·직장·자원(자금·체력·스트레스·선명도), 하단에 3축 카드·3칸 계획·「추천 계획」「지난달처럼」·시작 버튼. 활동 칸에는 올려 주는 능력치 태그를 미리 보여 준다.
- 활동 고르기: 6개 탭(공부·일·돈·관계·나·휴식), 가장 부족한 축의 탭이 기본으로 열린다.
- 시작 설정: 한 화면에 질문 하나(이름→학과→전직→후회).
- 전화하기(📞): 친구·엄마·썸·연인에게 한 달 2회, 활동 칸을 쓰지 않는다. 호감이 낮은 썸은 안 받을 수도 있다.
