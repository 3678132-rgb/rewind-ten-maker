# 다시, 스무 살 (Rewind Ten)

마흔에 이혼하고 해고된 주인공이 시간 약방 할머니의 약을 먹고 2006년의 스무 살로 되감긴다.
**십 년(120개월) 안에** 일·관계·나 세 축을 모두 50 이상 세우면 시계가 온전히 내 것이 되고(자유 엔딩),
못 하면 비 오는 골목의 마흔으로 돌아간다(회귀 엔딩). 「스테이지 제로 메이커」(1편)의 육성 시뮬레이션 엔진을 새 세계관으로 다시 짠 게임.

## 실행
`index.html`을 브라우저로 열면 된다 (단일 파일, 외부 의존성 없음).

## 개발
```
src/engine.js         상태·활동·정산 (DOM 금지)
src/data/lovers.js    연애 인물 4명과 연애 이벤트
src/data/events.js    스토리·시대(2006~2016)·랜덤 이벤트
src/data/endings.js   엔딩 판정과 편지 (12종)
src/ui.js, style.css, shell.html   화면
build.mjs             src → index.html
sim.mjs               자동 플레이 테스트
```
```
node build.mjs        # index.html 생성
node sim.mjs 1500     # 오류 {} 이고 smart 자유율 ≈ 70%, random ≈ 0% 이면 정상
```
`// ==ENGINE==` ~ `// ==/ENGINE==` 구간(engine/lovers/events/endings)에는 DOM 코드를 넣지 않는다.

## 핵심 규칙
- **3축**: 일·관계·나. 한쪽만 하면 나머지가 마른다(균형).
- **기억 선명도**: 미래 지식을 쓸수록 흐려진다. 쓴 만큼 「빌린 인생」이 쌓이고 일 점수가 깎인다.
- **연애**: 공식 연인은 한 명. 서재우(전남편)는 습관을 고치지 못하면 결혼이 되풀이된다.
- 월 3칸 스케줄 → 결과 → 이벤트. 시대 이벤트: 2008 금융위기, 2009 아이폰, 2010 카카오톡, 2012 여름.

세계관 설정은 `docs/WORLD.md`.
