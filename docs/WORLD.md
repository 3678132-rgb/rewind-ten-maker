# 세계관

- 시점: 2026년의 마흔 살 → 2006년 3월의 스무 살. 십 년 뒤(2016년 2월)가 기한.
- 약방: 비 오는 날 골목 끝의 「시간 약방」. 약 이름은 「되감기」. 조건은 서른 살에 새 인생을 만들 것.
- 할머니 = 일흔 살의 나. 먼저 십 년을 살아 보고 한 가지를 놓친 뒤 같은 후회를 가진 사람에게 기회를 건네는 중.
  단서: 같은 손등 흉터(첫 점검) → 엄마의 반지(두 번째) → 내 입버릇(마지막 해) → 정체 공개(피날레).
- 새 인생의 기준: 일·관계·나 각 50 이상, 합 180 이상. 미래 지식으로 쌓은 몫(빌린 인생)은 인정되지 않는다.
- 인물: 서재우(전남편, 22) · 한민준(고향 친구, 20) · 윤하진(스타트업 대표, 27) · 은태오(사진작가, 28) · 엄마 · 친구 소연.
